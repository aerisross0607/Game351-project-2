# Game351-project-2
A Unity hovercraft game where the player can drive the vehicle, turn and hover above the ground
# About HoverCraft Game
Within this project we made a hovercraft driving game made with Unity.

The hovercraft uses the physic based movement and stays above the terrain. The audio will also change pitch based on movement, if you move forward you can hear the acceleration, and the same for backward.

# Controls
W and Forward Arrow - move forward  
A and Left Arrow - move left  
S and Down Arrow - move backward  
D and Right Arrow - move right  

# Features
Physics-based hovering  
Steering, acceleration, and deceleration  
terrain hivering  
car options ( with variations between them )  
engine sound  

# Build With
Unity  
C#  
Rigidbody physics  
audio source
